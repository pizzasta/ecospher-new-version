# Ecosphere on web, PWA, and native (iOS/Android)

**Stack reality:** Ecosphere is **Vite + React + plain CSS**, not Next.js/Tailwind.
That's an advantage here — Capacitor wants a **static SPA** (`dist/`), which Vite
produces directly, with no `next export`/SSR juggling. One codebase ships three
ways:

1. **Web** (desktop + mobile) on Vercel — already live.
2. **Installable PWA** — `manifest.webmanifest` + `sw.js` already in `public/`.
3. **Native iOS + Android** via Capacitor wrapping the same `dist/`.

## 1. PWA (already 90% done)

- `index.html` has `viewport-fit=cover`, theme-color, Apple meta. ✓
- `public/manifest.webmanifest` — standalone, dark `#030712`, SVG icon. ✓
- `public/sw.js` — network-first shell cache. ✓

To finish it: add **PNG icons** (192, 512, and a 512 maskable with safe padding)
alongside the SVG — some installers ignore SVG-only manifests:

```json
"icons": [
  { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" },
  { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png" },
  { "src": "/icon-512-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" },
  { "src": "/favicon.svg", "type": "image/svg+xml", "sizes": "any" }
]
```

Manifest best practices for a dark, immersive app: `display: "standalone"`,
matching `background_color` + `theme_color` (`#030712`) so there's **no white
flash** on launch, `orientation: "portrait"`, and a maskable icon with ~20%
padding so Android's circle/squircle mask doesn't crop your sigil.

## 2. Capacitor — init & config

```bash
npm i -D @capacitor/cli
npm i @capacitor/core @capacitor/ios @capacitor/android
npx cap init Ecosphere app.ecosphere.signal --web-dir=dist
```

`capacitor.config.ts` (root):

```ts
import type { CapacitorConfig } from '@capacitor/cli'

const config: CapacitorConfig = {
  appId: 'app.ecosphere.signal',
  appName: 'Ecosphere',
  webDir: 'dist',
  backgroundColor: '#030712',          // no white flash
  ios: { contentInset: 'always', backgroundColor: '#030712' },
  android: { backgroundColor: '#030712' },
  plugins: {
    SplashScreen: { backgroundColor: '#030712', showSpinner: false, launchAutoHide: true },
  },
}
export default config
```

Then add platforms (creates native folders):

```bash
npm run build          # produces dist/
npx cap add ios
npx cap add android
npx cap sync
```

> Note: `capacitor.config.ts` imports `@capacitor/cli` types. Keep it OUT of the
> app's `tsconfig` `include` (which is `src` only) so the web typecheck doesn't
> require the dep, or only add it once Capacitor is installed.

## 3. Folder structure changes (minimal)

```
/                       ← unchanged Vite app
  capacitor.config.ts   ← new
  ios/                  ← generated by `cap add ios`   (commit it)
  android/              ← generated by `cap add android`(commit it)
  src/lib/platform.ts   ← new: tiny capability shim (below)
  public/manifest.webmanifest, sw.js  ← already there
```

You do **not** restructure `src/`. The whole React tree is reused as-is.

A small platform shim keeps native-only calls behind a guard so web stays clean:

```ts
// src/lib/platform.ts
import { Capacitor } from '@capacitor/core'
export const isNative = () => Capacitor.isNativePlatform()
export const platform = () => Capacitor.getPlatform() // 'web' | 'ios' | 'android'
```

## 4. Audio recording permissions + background audio

You already record via `getUserMedia` + `MediaRecorder` (web APIs). On native,
Capacitor's WebView supports `getUserMedia`, but you must declare permissions:

- **iOS** — `ios/App/App/Info.plist`:
  ```xml
  <key>NSMicrophoneUsageDescription</key>
  <string>Ecosphere uses your mic only while you're recording a signal.</string>
  ```
  For lock-screen/background audio playback, enable the **Audio** background mode
  (Xcode → Signing & Capabilities → Background Modes → "Audio, AirPlay…").
- **Android** — `android/app/src/main/AndroidManifest.xml`:
  ```xml
  <uses-permission android:name="android.permission.RECORD_AUDIO" />
  <uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
  ```

Your existing **Media Session API** work already drives lock-screen controls;
it keeps working inside the native WebView, so background playback "just works"
once the iOS background-audio capability is on. No native audio plugin needed
unless you want true background *recording* (you don't — recording is foreground).

## 5. Safe areas / notch (done in this repo)

`viewport-fit=cover` is set, the bottom nav already pads
`env(safe-area-inset-bottom)`, and `.content-well` now pads all four
`env(safe-area-inset-*)`. For any *fixed* overlay you add (bells, toasts),
offset with `top: max(12px, env(safe-area-inset-top))`. On native, Capacitor's
`contentInset: 'always'` (iOS) plays nicely with these.

## 6. Keeping the poetic UI feeling native

- **Kill the white flash** — matching `background_color`/`backgroundColor`
  everywhere (done) is the single biggest "feels native" win for a dark app.
- **Disable overscroll glow / bounce** where it breaks immersion:
  `overscroll-behavior: none` on the scroll container; on iOS WebView set
  `contentInset` and avoid rubber-banding the whole page.
- **No tap-highlight**: `* { -webkit-tap-highlight-color: transparent; }` and
  `touch-action: manipulation` to remove the 300ms delay.
- **Hide the status-bar contrast issues**: set the native status bar to dark
  content over your `#030712` (Capacitor `@capacitor/status-bar`, style `Dark`).
- **Haptics** as progressive enhancement (`@capacitor/haptics`) on key rituals —
  guarded by `isNative()`; web silently skips (iOS Safari has no vibration).
- Respect `prefers-reduced-motion` (already pervasive) — doubly important on
  native where heavy animation drains battery.

## 7. Deployment workflow — web vs native

**Web / PWA (instant):** push to the branch → Vercel builds `dist/` → live.
PWA users get the update on next load (SW is network-first).

**Native (deliberate):** native apps embed the web build, so:
```bash
npm run build        # fresh dist/
npx cap sync         # copy dist/ into ios/ + android/, update native deps
npx cap open ios     # → Xcode → Archive → App Store Connect
npx cap open android # → Android Studio → Generate Signed Bundle → Play Console
```
Two cadences: **web ships continuously**, **native ships per app-store release**.
Tip: for small fixes you can update the web without re-submitting native by
pointing Capacitor at a remote URL (`server.url`) — but that trades the offline
benefit and complicates review, so prefer bundling `dist/` and shipping updates.

## 8. Gotchas for animated / heavy UI

- **Battery & jank**: cap `requestAnimationFrame` loops to ~30fps, **pause all
  animation when the page is hidden** (you already gate several on
  `document.hidden`), and stop ambient audio in the background. WebView is less
  forgiving than mobile Safari.
- **`backdrop-filter`** (your `.glass`) is GPU-cheap on modern devices but can
  stutter on old Android WebViews — keep blurred layers few and large, not many
  and small.
- **`100vh` is wrong on mobile** — you already use `100dvh`; keep doing that.
- **AudioContext needs a user gesture** to unlock on iOS — you already start it
  on first interaction; make sure the *first* native tap unlocks it.
- **SVG filter noise / grain** can be expensive fullscreen — the grain overlay
  is tiled + low-opacity (good); avoid animating large blurred elements at high
  fps.
- **Storage**: `localStorage` + `IndexedDB` work in the WebView, but iOS can
  evict them under storage pressure — your "local-first but backend-mirrored"
  model already tolerates that.
- **Keyboard**: on native, the on-screen keyboard resizes the WebView; use
  `@capacitor/keyboard` resize mode `native` and keep composers (Cast a Line,
  notes) clear of the bottom inset.

## TL;DR

Your Vite SPA + the PWA assets you already have are 95% of the way there. Adding
Capacitor is: install three packages, one `capacitor.config.ts`, `cap add
ios/android`, declare mic permissions + iOS background-audio, and you ship the
same `dist/` to web, PWA, and both stores — with the safe-area + Media Session +
reduced-motion work already done in this codebase doing the heavy lifting for
"feels native."
