# Ecosphere Identity

Ecosphere is a cinematic emotional audio-social app.

It should feel like late-night internet loneliness, anonymous voice signals, replayed memories, drift, silence, and emotional frequencies.

## Core Themes

- anonymous after-dark network
- replayed memories
- anonymous voice signals
- late-night internet
- drift
- silence
- emotional frequencies

## Visual Identity

- black and navy backgrounds
- hot pink glow
- cyan accents
- violet gradients
- floating particles
- glassmorphism
- CRT texture
- sparse cinematic layouts
- oversized typography

## Voice

Cyber-noir: a futuristic night network. Short, direct, high-tech, still anonymous and after-dark. Say what a thing does — no vague poetry.

Page names: Signal Command (home), Live Feed, Signal Radar, Voice Channels, Dead Drop, Relays, Time Locks, Artifacts, Dark Zones, The Stream, Glitches, My Node, System.

Use copy like:

- "You're on the grid."
- "Transmit today or your streak goes dark."
- "Intercept one before it leaves the screen."
- "Channels that went dark. Bring them back online."
- "Voice moments the network refused to delete."

Keep safety language plain: never claim encryption, monitoring or rescue; "not a crisis service" stays.

## Never Let It Feel Like

- productivity software
- ecosystem simulation
- crypto UI
- corporate dashboards
- analytics software

Future changes should preserve the feeling of a quiet emotional audio world, not a conventional dashboard.
