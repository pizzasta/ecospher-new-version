# Ecosphere Identity

Ecosphere is a cinematic emotional audio-social app.

It should feel like late-night internet loneliness, anonymous voice signals, replayed memories, drift, silence, and emotional frequencies.

## Core Themes

- loneliness
- replayed memories
- anonymous voice signals
- late-night internet
- drift
- silence
- emotional frequencies

## Visual Identity

- black and navy backgrounds
- hot pink glow
- cyan accents
- violet gradients
- floating particles
- glassmorphism
- CRT texture
- sparse cinematic layouts
- oversized typography

## Voice

The app should sound human, mysterious, intimate, and atmospheric.

Use copy like:

- "You crossed someone's mind again."
- "This signal refuses to disappear."
- "Someone nearby stayed longer than expected."
- "Recovered from emotional drift."
- "Quiet replay activity detected."

## Never Let It Feel Like

- productivity software
- ecosystem simulation
- crypto UI
- corporate dashboards
- analytics software

Future changes should preserve the feeling of a quiet emotional audio world, not a conventional dashboard.
